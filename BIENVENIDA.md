# 🎉 ¡Bienvenido a BakerySoft!

## 🍞 Sistema de Gestión para Panaderías

**BakerySoft** es un sistema completo de gestión diseñado específicamente para panaderías, con control de inventario, personal, finanzas, producción, ventas y más.

## 👥 Roles y Permisos

### 👑 Administrador
**Acceso completo a todos los módulos**
- Dashboard, Inventario, Personal, Finanzas
- Producción, POS, Reportes, Proveedores
- Pedidos, Productos, Usuarios, Perfil

### 👔 Gerente
**Gestión operativa completa**
- Dashboard, Inventario, Personal, Finanzas
- Producción, POS, Reportes, Proveedores
- Pedidos, Productos, Perfil
- ❌ Sin acceso a Usuarios

### 👷 Supervisor
**Supervisión de operaciones**
- Dashboard, Inventario, Personal
- Producción, POS, Pedidos, Productos, Perfil
- ❌ Sin acceso a Finanzas, Reportes, Proveedores, Usuarios

### 👨‍🍳 Empleado
**Operaciones básicas**
- Dashboard, Inventario, Producción
- POS, Productos, Perfil
- ❌ Sin acceso a gestión administrativa

### 🛒 Cliente
**Vista de cliente**
- Dashboard, Productos, Pedidos, Perfil
- ❌ Sin acceso a módulos administrativos

## 🛠️ Tecnologías

### Frontend
- **React 18** - Framework de UI
- **Vite** - Build tool
- **Tailwind CSS** - Estilos
- **Context API** - Gestión de estado

### Backend
- **Express.js** - Framework de servidor
- **PostgreSQL** - Base de datos
- **JWT** - Autenticación
- **bcrypt** - Encriptación

### Deployment
- **Vercel** - Hosting frontend
- **Vercel Postgres (Neon)** - Base de datos
- **GitHub** - Control de versiones
